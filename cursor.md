# SiteCopilot AI – Project Rules

## Project Overview

SiteCopilot AI is an AI-powered field operations platform designed to help construction companies manage projects, site activities, workers, materials, and reporting through intelligent automation. The goal is to reduce manual work, improve project visibility, and streamline communication across construction sites.

## Tech Stack

### Frontend

- React
- TypeScript
- Vite
- Tailwind CSS

### Backend

- Node.js
- Express.js

### Database

- PostgreSQL

### Authentication

- JWT
- bcrypt

### AI

- OpenAI API (or compatible LLM)

## Code Standards

- Write clean, readable, and maintainable code.
- Use ES6+ and modern JavaScript/TypeScript features.
- Prefer functional React components with hooks.
- Follow component-based architecture.
- Keep components small and reusable.
- Use descriptive variable, function, and component names.
- Avoid duplicate code (DRY principle).
- Add comments only when they improve understanding.
- Use async/await instead of nested promises where possible.
- Handle errors gracefully and provide meaningful messages.
- Keep files organized by feature.

## UI/UX Guidelines

- Design for mobile-first, then desktop.
- Build clean, modern, and professional interfaces.
- Prioritize usability for construction workers and project managers.
- Use accessible components and responsive layouts.
- Keep navigation simple and intuitive.

## AI Development Guidelines

When generating code:

- Prefer scalable and production-ready solutions.
- Explain complex implementations when necessary.
- Avoid unnecessary dependencies.
- Recommend best practices where appropriate.
- Prioritize performance and security.
- Generate modular, reusable code.

## Git Workflow

Follow Conventional Commits for every commit.

Examples:

- feat: add worker attendance module
- feat: implement AI daily report generation
- fix: resolve authentication issue
- docs: update project documentation
- style: improve dashboard layout
- refactor: simplify report generation service
- test: add authentication tests
- chore: configure development environment

## Project Goal

Build a scalable SaaS platform that can evolve into Africa's leading AI-powered operating system for construction and field operations.
